# Shrink Wizard

Free up disk space on your Mac or Windows PC with lossless compression.

[Website](https://shrinkwizard.com) · [Download](https://shrinkwizard.com/download) · [Report a bug](https://github.com/ecc521/Shrink-Wizard/issues/new/choose) · [Request a feature](https://github.com/ecc521/Shrink-Wizard/issues/new/choose)

## About the app

Shrink Wizard compresses apps, files, and photos to reduce the space they use.
It supports transparent filesystem compression on macOS and Windows, lossless
JPEG optimization, and reversible JPEG XL recompression.

The current release is free, with unlimited compression.

### Downloads

Visit the [download page](https://shrinkwizard.com/download) for installers and
setup instructions:

- **Mac:** macOS 13 or later, on Apple Silicon or Intel.
- **Windows:** Windows 10 or 11, on x64 or ARM64.

## What this repository is for

This is the public home for Shrink Wizard bug reports, feature requests, and
release announcements. The application's source code is currently private.

- [Report a bug or suggest a feature](https://github.com/ecc521/Shrink-Wizard/issues/new/choose).
- [Browse existing issues](https://github.com/ecc521/Shrink-Wizard/issues).
- [View releases](https://github.com/ecc521/Shrink-Wizard/releases).
- For account, billing, or other private support, email
  [support@shrinkwizard.com](mailto:support@shrinkwizard.com).

Please search existing issues before opening a new one. Include your app
version and operating system when reporting a bug. Remove private file paths
and personal information from screenshots and logs before posting.

For security concerns, please follow [SECURITY.md](SECURITY.md).
